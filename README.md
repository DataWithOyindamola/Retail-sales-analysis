Project Overview

This project analyses retail sales data to identify revenue trends, top-performing product categories, regional performance, and sales channel contributions.

Tools Used

Microsoft Excel

Power BI

Microsoft Word

Key Findings

Total sales: ₦80,259.39 across 140 transactions.

Top-performing category: Fashion, generating ₦22,094.57.

Leading region: Central, generating ₦21,339.74.

In-store sales contributed 58% of total revenue.

Project Work

Cleaned and standardised sales data.

Addressed missing values and inconsistencies.

Analysed sales by category, region, and channel.

Developed a revenue forecast in Excel.

Built an interactive Power BI dashboard.
